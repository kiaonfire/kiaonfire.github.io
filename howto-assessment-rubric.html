Assessment · Quick how-to

Create a clear and useful rubric

Build criteria students can understand before submission and staff can use consistently when judging the intended learning.

Framework practices used here

This how-to pulls together several parts of the Inclusive Teaching Framework rather than treating the issue as belonging to one area.

LanguageAccessibilityRespect

Quick steps

1
Start from the learning outcomes, not from inherited rubric categories.
2
Use concrete language to describe what quality looks like.
3
Remove vague labels such as “professional” unless you define the observable capability.
4
Use exemplars or a short walkthrough to show how criteria apply in practice.

Use these framework practices

Language & literacies

Write clear assessment instructions and criteria

Write instructions in plain, direct language without losing disciplinary precision.

Accessibility

Make assessment criteria and materials accessible

Check rubrics, exemplars and task sheets for clarity and accessibility.

Language & literacies

Use annotated exemplars to show what good looks like

Provide more than a finished sample by annotating what makes it effective.

Respect & representation

Check cultural assumptions and hidden norms

Check whether the task rewards one style of expression when that style is not the learning outcome.

Example in practice

A rubric replaces “excellent professional presentation” with specific criteria for audience awareness, structure, evidence and clarity.
