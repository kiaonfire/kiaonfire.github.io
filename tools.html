Redesigned review suite

Tools redesigned around the UQ framework.

These tools retain the accessible design language and the helpful implementation mindset from the UNSW guide, but reorganise review around your own framework. Instead of a long generic checklist, staff can now review the course using your three sections and four interacting dimensions.

How to use the tools

  1. Select the level that best describes the current course.
  2. Add notes about barriers, strengths or context.
  3. Look for patterns across the dimensions.
  4. Generate an accessible HTML report.

Key tenet These dimensions interact. A student may face barriers across several categories simultaneously, and the strongest inclusive practice addresses them in combination rather than ticking each off independently. When using this tool, consider your course or teaching as a whole and look for patterns across dimensions rather than treating each row in isolation.

This prototype keeps the best aspects of the UNSW implementation approach by supporting a pathway from immediate baseline improvements through deeper redesign and finally more embedded and holistic practice. The exported report groups actions into those same implementation horizons.
