Accessibility statement

Designed for strong accessibility, not declared perfect.

This prototype restores the earlier accessibility design features and applies them across the tools and the exported report format.

Features included

  • Semantic headings, landmarks and navigation
  • Skip links and strong visible keyboard focus
  • Light, dark and high-contrast themes
  • Larger text and roomier spacing options
  • Responsive layouts that reflow at smaller widths and higher zoom
  • No reliance on colour alone for review status meaning
  • Accessible HTML report export with semantic headings and a structured table
  • Print styles for both the site and exported report

Formal WCAG 2.2 conformance cannot be claimed without manual testing, screen-reader testing, voice-control testing and user testing with disabled and neurodivergent people.

Accessibility still needs ongoing testing.

Even strong prototypes need review with real users, assistive technologies and final platform conditions.
